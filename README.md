# 経費申請

氏名は1回入力し、経費明細を最大8件まとめて提出できます。明細ごとに写真を1〜5枚、1申請につき合計12枚まで添付できます。申請日を日本時間で先頭に表示し、利用日は明細ごとに入力します。写真は添付前にプレビューでき、文字読み取りも任意で実行できます。用途の入力欄はありません。既存台帳ではセットアップの再実行で用途列が非表示になり、過去のデータは保持されます。

## Google Workspaceで使い始める

1. 管理用のGoogle WorkspaceアカウントでApps Scriptプロジェクトを開きます。既存の経費申請プロジェクトがある場合はそちらを使います。
2. 既存の `コード.gs` に `Code.gs` を貼り付け、HTMLファイル「Index」に `Index.html` を貼り付けます。
3. 「プロジェクトの設定」で `appsscript.json` を表示して同梱の内容に差し替え、保存します。標準Google Cloudプロジェクトを紐づけている場合は、Drive APIとSheets APIを有効にしてください。
4. エディタで `setupExpenseApp` を選んで実行し、表示される権限を確認します。作成された「経費申請台帳」と「経費申請｜証憑」のURLが実行ログに出ます。セットアップを再実行すると同じ台帳とフォルダを使います。
5. 「デプロイ」から「ウェブアプリ」を選び、実行ユーザーをデプロイ担当者に設定します。最初は自分のみでテストします。配布対象が組織内アカウントであれば、承認後に組織内公開へ変更できます。社外アカウントの配布員がいる場合は、利用者の認証方法を先に決めます。
6. テスト用画像で、複数明細・複数写真をまとめて提出します。台帳に同じ受付番号の明細が1件1行で入り、各写真リンクから画像を確認できることを確かめます。台帳と画像フォルダの閲覧権限は確認担当者にだけ付与します。

[Apps Script ウェブアプリのデプロイ](https://developers.google.com/apps-script/guides/web)

## キャラバンの交通費

- 自宅最寄駅から集合駐輪場の最寄駅までの運賃と、同じ自宅最寄駅から最寄り事務所の駅までの運賃を入力します。
- 利用した運賃種別（IC・切符）と対象範囲（片道・往復）を選びます。両区間とも同じ範囲の運賃を入力してください。往復を選んだ場合、入力・検索するのは往復分です。
- 集合駅までの運賃から事務所までの運賃を引き、画面と台帳に反映します。集合駅の方が安い場合は申請額を0円にします。事務所駅と自宅最寄駅が同じ場合は、候補検索で0円が入ります。
- 集合駅・事務所駅ごとに、利用日とIC／きっぷの設定を引き継いで、無料のYahoo!路線情報を別タブで開けます。往復の場合は帰りの検索リンクも表示します。検索先に渡す項目は駅名・日付・検索条件です。
- 駅を入力すると、利用日・IC／きっぷ・片道／往復の条件で運賃マスターを検索し、区間ごとに登録済みの最安運賃を自動入力します。実際に乗った経路に合わせて候補の変更や手入力もできます。候補がない区間は、検索先や利用履歴で確認して入力します。
- 自転車引き出し代は別の明細にし、現地の領収書・支払額が分かる写真を添付します。
- 既存の配布員向けマニュアルでは証憑の提出先が個人LINEグループです。アプリへの切替日は運用側で決めてください。

## 運賃マスターの入力

運賃データは空の状態で作成します。運賃を確認したうえで「運賃マスター」に次の項目を登録してください。経路や鉄道会社が異なる場合は同じ駅間でも行を分けて登録できます。

| 列 | 項目 | 入力方法 |
|---|---|---|
| A・B | 出発駅・到着駅 | アプリで入力する駅名を使います。駅名末尾の「駅」の有無は吸収します。 |
| C・D | 運賃種別・対象区間 | `IC` または `切符`、`片道` または `往復` |
| E | 運賃 | 円単位の整数 |
| F | 経路・鉄道会社 | 経路を見分けられる情報を入力します。例　JR埼京線 |
| G・H | 適用開始日・適用終了日 | `YYYY/MM/DD`。適用開始日は必須、適用終了日は空欄可。 |

駅名入力後に利用日時点の運賃を取得し、見つかった区間ごとに最安の候補を自動入力します。「登録運賃を再検索」で確認し直せます。マニュアルの計算例の金額は実際の運賃として登録していません。Yahoo!路線情報へのリンクには、API利用契約・アクセスキーは不要です。検索結果の金額をアプリへ自動転記する機能はありません。

## 画面の確認

ZIP内の `Index.html` を開くと、日付、明細追加、画像添付、経路検索リンク、差額計算、合計を確認できます。単体プレビューではデータを保存しません。運賃マスター検索・文字読み取り・提出はApps Scriptと台帳の設定後に動作します。

[Yahoo!路線情報の経路・運賃の検索方法](https://support.yahoo-net.jp/SccTransit/s/article/H000015030)

## 申請された運賃を次回に使う

「経費明細」には、申請者が手入力した運賃と駅間が提出時に記録されます。
領収書・IC履歴や経路検索で確認したら、再利用してよい区間の期限を入力します。
AA列が集合駅、AB列が事務所駅です。日付は `YYYY-MM-DD` で入力します。
期限は利用日以降の日付を指定してください。次回の申請では、その利用日から期限までの範囲内で、駅間・IC／きっぷ・片道／往復が一致する運賃を再利用します。
期限が空欄の申請や、同じ条件で確認済みの金額が食い違う場合は手入力できます。
「運賃マスター」に有効な候補がある場合は、その候補が優先されます。
運賃を再利用する設定は、経費そのものの承認とは別です。
